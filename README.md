# Thi Trắc Nghiệm – Multiple-Choice Exam

A Windows 10/11 app for taking multiple-choice exams and practice tests. Works fully offline, with a Moodle-style test interface.

## ⬇️ Download

👉 **[Download the latest version](https://github.com/hoangvclvacc/multiple-choice-system-release/releases)**

On the page that opens, scroll down to **Assets** and download `ThiTracNghiem-Setup-….exe`.

## 💻 Installation

1. Run the downloaded `ThiTracNghiem-Setup-….exe`.
2. If Windows shows **"Windows protected your PC"**, click **More info → Run anyway**. The warning appears only because the app is not code-signed. It is not a virus warning.
3. Click **Next** until the installation finishes. No administrator rights are needed.
4. Start the app from the **Thi Trắc Nghiệm** shortcut on your desktop.

## 📝 Taking a test

1. Get the **`.dethi`** exam file from your teacher or exam organizer (via Zalo, USB, email…).
2. **Double-click** the file to open the exam in the app.
3. Enter your name and click **"Bắt đầu làm bài"** (Start).
4. When you're done, click **"Nộp bài và kết thúc"** (Submit and finish), then **"Tải file kết quả"** (Save result file), and send that file back to your exam organizer.

Notes:
- Your answers are saved continuously. If the computer shuts down or loses power, open the exam file again to continue. The timer keeps running in real time.
- Some exams use **lockdown mode**: the app stays full-screen until you submit, and every attempt to leave the exam window is recorded.

## 🔄 Updates

The app **checks for and downloads new versions automatically** whenever the computer is online. When an update is ready, the home screen asks **"Cài đặt ngay / Để sau"** (Install now / Later).
Updates never happen while a test is in progress.

## ❓ Troubleshooting

- If the app opens to a blank white screen or shows an error, uninstall it and reinstall the latest version from the link above.
- If the problem continues, send the log file to your support contact. Paste `%APPDATA%\ThiTracNghiem\nhatky.txt` into the File Explorer address bar to open it.
